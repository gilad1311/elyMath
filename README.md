# עולם הלמידה שלי — כיתה ב׳

אתר לימודי בעברית לילדי כיתה ב׳, מבוסס React + Vite ומוכן לפרסום ב-GitHub Pages.

## מה יש באתר?
- חשבון: משחקוני חיבור, חיסור והשוואת מספרים.
- עברית: אוצר מילים והבנת הנקרא.
- אנגלית: מילים בסיסיות ותרגום.
- מדעים: שאלות על צמחים, מים וגוף האדם.
- פינת קריאה וכתיבה עם סיפור קצר ומשימת כתיבה.
- קישורים לאתר אופק ולחיפושי סרטונים לימודיים.
- ניקוד שנשמר בדפדפן של אותו מכשיר.

## הרצה מקומית
```bash
npm install
npm run dev
```

## בנייה
```bash
npm run build
```

## פרסום ב-GitHub Pages
1. העלו את כל קובצי הפרויקט ל-root של repository.
2. היכנסו ל-Settings → Pages.
3. תחת Build and deployment בחרו `GitHub Actions`.
4. הקובץ `.github/workflows/deploy.yml` יבנה ויפרסם את האתר בכל push ל-`main`.
5. המתינו לסיום הפעולה בלשונית Actions. כתובת האתר תופיע ב-Settings → Pages.

## התאמה
אם שם ה-repository שונה, `vite.config.js` משתמש ב-`base: './'`, כך שהנתיבים היחסיים מתאימים בדרך כלל ל-GitHub Pages.

## הערה על קישורים
הקישורים לסרטונים נפתחים בחיפוש YouTube לפי נושא, כדי שלא להסתמך על סרטון בודד שעלול להיעלם. קישורים ישירים לאופק ולגלים פרו עשויים לדרוש הרשאה או התחברות. בדקו את התאמת התוכן לגיל לפני השימוש.
